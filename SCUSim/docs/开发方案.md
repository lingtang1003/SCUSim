## 0. 关键架构决策（理由与影响）—— 如需变更须先确认

| # | 决策 | 理由 | 影响 |
|---|---|---|---|
| 1 | 新增 `src/config/schema.js`（纯校验函数），与 `loader.js` 分离 | `loader` 依赖浏览器 `fetch`/`import.meta.url`，无法在 Node 测试环境直接测；纯校验函数可在 Node 跑配置校验与异常用例 | `loader.js` 调用 `schema`；`tests/` 直接 import `schema`；不引入新运行时依赖 |
| 2 | 状态模型＝**可变状态 + 明确所有权** | 四人协作、避免不可变深拷贝的性能和一致性陷阱；复现性由 RNG 种子保证，不靠不可变 | 所有 core 函数就地改 `state` 并返回结果；UI 绝不改 `state`；须在文档固化“各模块可写字段” |
| 3 | 配置加载＝相对路径 + `import.meta.url` + **可注入 reader** | 满足 Pages 子路径/预览/自定义域名的相对路径要求；同时让 Node 测试注入本地读取器；不硬编码 `localhost` | `loader` 默认用 `fetch(import.meta.url)`；测试注入 `reader`；属 loader 内部实现 |
| 4 | RNG 内部状态序列化进 `GameState.rngState` | 读档后随机序列连续且可复现；契合“相同种子相同输入可复现”验收 | `GameState` 增 `rngState`；导入存档后需 `setState` 还原 |
| 5 | 版本不兼容＝**直接拒绝并提示**（暂不做迁移） | 说明书未要求版本迁移 | `importSaveFile` 对不兼容 `version` 返回 `{ok:false,reason}` 且不覆盖 |

> 若团队坚持“不可变状态”或“自动迁移”，须全员确认并更新 `INTERFACES.md` 与 `DATA_DICTIONARY.md` 后再编码。

## 1. 项目需求与技术限制总结

### 1.1 玩法需求（必须实现）
- 主题：四川大学**校园生活模拟**单机 Web 游戏；浏览器内运行，无传统后端。
- 单局 **40 回合**（每回合＝1 个月，＝8 学期，每 5 回合一学期）。
- 每回合 **4 个行动点**，行动消耗 AP。
- 角色创建四步：姓名/性别 → 选学院 → 分配 **20 点**属性（学识/社交/健康/金钱）→ 从 6 个标签选 **3 个**。
- **六类行动**；基础随机事件概率 **35%**，权重受标签/学院/学年修正。
- 固定事件：社团招新、毕业论文。
- 学业：每学期考试；**挂科累计 3 门**触发学业警告。
- 结局：条件来自 `endings.json`，多结局命中按**优先级**取最高；结局图鉴**跨周目保留**。
- 配置规模（来自概要设计，不得删减）：**8 学院 / 12 标签 / 6 行动 / 16 事件（2 固定+14 随机）/ 6 结局**。
- 质量：配置校验、错误处理、自动存档、存档导入导出、结局图鉴、回归测试。

### 1.2 技术约束（硬红线）
- **ECMAScript 2020 ES Modules**；原生 HTML/CSS/JS；**不用** Vue/React 等框架。
- **不用**打包器或第三方运行时库（架构变更须批准）。
- Node ≥16 仅用于本地静态服务器与测试脚本。
- 必须经 **HTTP** 运行（入口 `http://localhost:5173`），**禁止** `file://` 打开模块。
- 业务逻辑全在浏览器本地执行；默认**无后端**。
- 核心逻辑/事件层**不得**依赖 DOM / IndexedDB / LocalStorage；依赖单向、无循环依赖。
- UI **不得**直接改写 `GameState`。
- 随机数**唯一入口** `src/core/rng.js`，核心逻辑禁写 `Math.random()`。
- 游戏数值**全部配置驱动**，不得硬编码到 JS。

### 1.3 默认不包含（范围边界）
用户注册/登录、云端存档、跨设备同步、多人联机、业务 API、SSR、收集个人敏感信息。
> 跨设备云同步如需，必须作为**第二阶段**单独评估 Cloudflare Workers + D1 + 认证，并说明成本；不得混入当前静态版。

### 1.4 部署目标
- 本地可运行；Cloudflare Pages 静态托管获得真实公网地址；可选绑定自定义域名 + HTTPS。
- 纯静态，**不**依赖开发者电脑常驻；`server.js` 只用于本地开发。

## 3. 项目目录结构、模块依赖与统一接口

### 3.1 目录结构（在 01 §4 建议基础上，新增 `docs/` 与 `schema.js`）
```text
SCUSim/
├── index.html                # 站点入口（表现层）
├── package.json              # 仅 dev / test 脚本，无 build
├── server.js                 # 本地静态服务器（Node http，无依赖）
├── README.md                 # 运行/部署/存储限制说明
├── config/                   # 配置驱动层（6 份 JSON）
│   ├── balance.json          # 数值/概率/规则参数
│   ├── colleges.json         # 8 学院
│   ├── tags.json             # 12 标签
│   ├── actions.json          # 6 类行动（含 cost/条件/效果/requiresHealth）
│   ├── events.json           # 16 事件（2 固定 + 14 随机，含权重/选项/结果）
│   └── endings.json          # 6 结局（条件/优先级/展示）
├── css/
│   └── style.css
├── src/
│   ├── main.js               # 协调层（A）：装配 config/engine/storage/ui
│   ├── core/
│   │   ├── rng.js            # 随机数唯一入口（A）
│   │   ├── state.js          # GameState 工厂/克隆（A）
│   │   ├── engine.js         # 回合主流程（A，编排 B 模块）
│   │   ├── economy.js        # 经济（B）
│   │   ├── academy.js        # 学业/考试（B）
│   │   └── ending.js         # 结局判定（A）
│   ├── config/
│   │   ├── loader.js         # 浏览器加载+校验（D）
│   │   └── schema.js         # 纯校验函数（D，决策#1）
│   ├── events/
│   │   └── eventManager.js   # 事件触发/结算（B）
│   ├── storage/
│   │   └── storage.js        # IndexedDB+降级（D）
│   └── ui/
│       └── ui.js             # 表现层（C）
├── docs/
│   ├── DATA_DICTIONARY.md    # 本包已建（草案）
│   ├── INTERFACES.md         # 本包已建（草案）
│   └── 开发方案.md           # 本文件
└── tests/
    └── smoke.mjs             # 纯逻辑冒烟（D）：配置校验/40回合/随机复现/存档往返
```

### 3.2 模块依赖关系（箭头＝“依赖/调用”，单向、无环）
```text
ui(C) ──callbacks──▶ main(A) ──▶ engine(A)
                                │  ├─▶ state(A)  rng(A)  ending(A)
                                │  └─▶ economy(B) academy(B) eventManager(B)
main(A) ──▶ loader(D) ──▶ schema(D)
main(A) ──▶ storage(D)
config/*.json ──▶ loader(D) ──▶ (注入) engine/eventManager
```
- **禁止反向**：`core/`、`events/`、`config/` 不得 import `storage/`、`ui/` 或访问 `window`/`indexedDB`/`localStorage`/`fetch`（loader 的 `fetch` 是允许的，因其属配置驱动层且可注入 reader）。
- 纯逻辑模块可在 Node 直接 import 测试（决策 #3 的 reader 注入使其脱离浏览器）。

### 3.3 统一接口（已固化于 `INTERFACES.md`，要点）
- 统一返回：`{ ok, state?, data?, message?, reason? }`。
- RNG：`createRng(seed)` → `{next,int,chance,pick,getState,setState,fork}`。
- Engine：`newGame / actionAvailability / doAction / advance / resolvePendingEvent / getEnding`（均就地改 `state`）。
- Config：`loadConfig(reader?)` / `validateConfigs(configs)`。
- Storage：`saveGame/loadGame/clearSave/getGallery/unlockEnding/exportSaveFile/importSaveFile/getSettings/saveSettings`。
- UI：`createApp({config,callbacks})` → `{mount,render,showEvent,showEnding,showError,showGallery}`。
- 调用权：仅 `main.js` 串起 engine+storage+ui；UI 只走 callbacks。

## 5. 本地开发 → 测试 → Cloudflare Pages 部署流程

### 5.1 本地开发
- `package.json`（无构建步骤，不伪造 build）：
  ```json
  { "scripts": { "dev": "node server.js", "test": "node tests/smoke.mjs" } }
  ```
- `server.js`：纯 Node `http`，无第三方依赖；正确设置 MIME：
  - `.js`/`.mjs` → `application/javascript`
  - `.json` → `application/json`
  - `.html`/`.css` → 对应类型
  - 监听 `5173`，根目录为项目根；无 SPA 路由（单页多视图即可）。
- 访问 `http://localhost:5173`，禁止 `file://`。

### 5.2 测试
- `npm test` → `tests/smoke.mjs`（Node 直接跑纯逻辑，不启浏览器）：
  1. 配置校验：良/坏 `configs` 用例；
  2. 引擎：固定种子跑满 40 回合不越界；
  3. 随机复现：同种子同输入结果一致；
  4. 存档往返：导出→导入关键状态一致；坏文件不覆盖；
  5. 静态约束：`core/`、`events/`、`config/schema.js` 不含 `Math.random`、不含 `window`/`indexedDB`/`localStorage` 引用。
- 浏览器手测清单：角色创建四步、行动/事件/考试/结局、刷新继续、`.scusim` 导出下载、导入恢复、控制台无阻断错误。

### 5.3 部署到 Cloudflare Pages
**方式 A（推荐，连接 Git）：**
1. 提交到 GitHub/GitLab；登录 Cloudflare Dashboard → Workers & Pages → Pages → 创建。
2. 连接仓库；Framework preset 选 **None**；Build command **留空**（无构建）；Build output directory 设为含 `index.html`/`src/`/`css/`/`config/` 的目录（仓库根或 `public`）。
3. 部署后打开 `*.pages.dev` 验证：主菜单/创建/行动/事件/刷新/存档/导入导出。
4. 推送关联分支可自动部署。

**方式 B（直接上传静态文件）：** 控制台直接上传，适合一次性；协作/回滚不如 Git。

**自定义域名 + HTTPS：**
1. 自备可控域名（购买与部署是两件事）。
2. Pages 项目 → Custom domains → 添加域名 → 按指引配 DNS（CNAME 到 `*.pages.dev` 或按控制台给的 A/AAAA）。
3. 等验证 + 证书签发；无痕/异网访问确认资源与静态资源均加载；DevTools 查无混合内容/CORS/路径错误。
4. ⚠️ 不要将真实域名/Token/密码写入源码或仓库（03 §5）。

### 5.4 路径与静态资源注意（03 §6）
- 资源用稳定**相对路径**；配置用 `fetch(new URL('../config/x.json', import.meta.url))`（决策 #3）。
- 不写死 `http://localhost:5173`；在 `pages.dev`、预览域名、自定义域名下分别验证路径。
- `server.js` 只是本地开发服务器，**不是** Pages 生产后端。

### 5.5 部署验收清单（映射 03 §9 / 04 §8）
- [ ] `*.pages.dev` 可打开；自定义域名（若用）可打开且 HTTPS 正常
- [ ] 刷新无资源 404；六份配置 JSON 均加载
- [ ] 角色创建/行动/事件/考试/结局正常
- [ ] IndexedDB 存档 + 继续游戏正常；`.scusim` 导出可下载、导入可恢复、坏文件不破坏存档
- [ ] 正式域名下重测存档；控制台无阻断错误
- [ ] README 写明：浏览器本地存储限制、**默认不支持云同步**
