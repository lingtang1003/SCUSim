# 恋爱线 · 六角色剧情总表（v3.0 · 11 步三结局）

> 归属：**B（经济学业与事件）**。数据在 `config/storylines.json`（拓扑）与 `config/events-characters.json`（事件正文/选项效果）。
> 本文档是六条恋爱线的**唯一现行口径**；`docs/角色系统.md` §2 中的「4 步流程」为 v2.1 遗留描述，已不再适用。

## 1. 统一骨架（六线完全一致）

| 序号 | 步骤 id | 触发窗口 | 进入门槛 | 说明 |
|---|---|---|---|---|
| 1 | `meet` | 第 3–9 周 | 无 | 初遇，必触发 |
| 2 | `again` | 第 8–13 周 | 好感 ≥ 8 | 再遇，开始有对话 |
| 3 | `group` | 第 12–17 周 | 好感 ≥ 14 | 组队 / 合作邀请 |
| 4 | `homework` | 第 16–21 周 | 好感 ≥ 20 | 小组作业，单独相处 |
| 5 | `feel` | 第 20–25 周 | 好感 ≥ 26 | **分支点**：表白 → `date`；顺其自然 → `miss` |
| 6 | `date` | 第 24–29 周 | 好感 ≥ 32 | 约会 |
| 7 | `fight` | 第 28–32 周 | 好感 ≥ 38 | **分支点**：冷静 → `makeup`；不合适 → `drift` |
| 8 | `makeup` | 第 31–35 周 | 好感 ≥ 44 | 和解 |
| 9 | `happy` | 第 34–38 周 | 好感 ≥ 50 | 真结局，`@done` |
| 10 | `miss` | 第 26–31 周 | 无（由 feel 分支进入） | 错过，`@done` |
| 11 | `drift` | 第 31–35 周 | 无（由 fight 分支进入） | 疏远，`@done` |

选项 id 规范：`feel` = `brave` / `letitbe`；`fight` = `cool` / `quit`（**林予例外**：`makeup` / `breakup`）；`makeup` = `reconcile`；`happy` = `confess`；`miss` = `congratulate`；`drift` = `leave_door`。
`happy` 路径的告白选项必须排在第一位（G 段自动 play 取第一个 enabled 选项）。

## 3. 分支与好感增减

| 环节 | 选项 | 好感 | 去向 |
|---|---|---|---|
| feel | brave（表白） | +7 | → date |
| feel | letitbe（顺其自然） | 0 | → miss |
| fight | cool（冷静） | +4 | → makeup |
| fight | quit（不合适，林予为 breakup） | −4 | → drift |
| makeup | reconcile（互相理解） | +4 | → happy |
| happy | confess（告白/相拥） | +10 | `@done` 真结局 |
| miss | congratulate（祝贺） | −12 | `@done` 错过 |
| drift | leave_door（转身离开） | −18（钳到 0） | `@done` 疏远 |

单步正面选项基线：meet/group +7，again/homework/date +6；次要选项 +2（江叙 miss 前的 `letitbe` +0、林予 meet 的 `ignore` +0 例外）。

## 4. 结局判定（`config/endings.json`，priority 小者优先）

| 结局 | 条件 | 好感实测落点 |
|---|---|---|
| `ending_<角色>_true` | 线 `done` 且好感 ≥ 55（**周野/唐棠 ≥ 45**） | 63 |
| `ending_<角色>_warm` | 仅好感达标（其余 ≥ 30，周野/唐棠 ≥ 25），不要求走完 | — |
| `ending_warning` | 兜底（priority 99） | miss 线 20 / drift 线 23 |

miss 与 drift 的结尾好感均低于 warm 阈值，保证不会误留温暖结局。
