## 3. 手测

### 3.1 浏览器（未自动执行，给出手动步骤）

本机沙箱下 Edge 的 `--screenshot` 与 CDP 驱动会被拦截（`--screenshot` 进程直接崩溃，CDP 连接后 `Runtime.enable` 超时），
所以**像素级验证没跑**。功能结构与数据链路由上面的 52 项机器用例覆盖。手动复核：

```bash
node server.js          # http://localhost:5173
```

| # | 检查项 | 期望 |
|---|---|---|
| 1 | 新游戏 → 第 2 回合 | 弹出「迎新晚会」，7 个选项两列网格 |
| 2 | 选「林予 · 举着相机拍舞台」 | 好感 +6；HUD 出现「♡ 林予线 · 1/4」 |
| 3 | 第 3 回合 | 强制弹出「图书馆邂逅」，右侧出现林予立绘、底部对话框先播旁白 |
| 4 | 点对话框 2 次 | 切到「林予」台词；第 3 段播完后选项淡入，选项上带「↑ 林予 好感+10」 |
| 5 | 选「主动搭话」 | 对话框下方出现「▲ 林予 好感 +10」；右上 ♡ 打开关系面板，林予卡片显示「熟识 / 好感 16 / 片段 1/8」 |
| 6 | 走到第 40 回合 | 结局页出现角色真结局（最优路线）或「没说完的话」（保守路线） |
| 7 | 刷新 / 导出导入 | 剧情线进度与好感都还在 |
| 8 | 手机宽度（≤560px） | 事件里不显示 NPC 立绘，选项单列可滚动 |

另有 dev 专用回归页（不影响正式入口）：
`/dev/shot.html?scene=event&char=linyu&click=1&dev=1`（scene 可取 `welcome / event / result / relations`）。
