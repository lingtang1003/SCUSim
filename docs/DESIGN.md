# SCUSim · DESIGN.md

> 视觉小说（橙光式）界面设计系统。格式对齐 Google Stitch 的 DESIGN.md：
> 纯文本描述设计决策，便于人和 AI Agent 一致地生成/修改界面。
> 对应实现：`css/style.css`（令牌 + 组件）与 `src/ui/ui.js`（结构）。

---

## 1. Visual Theme & Atmosphere

**一句话**：白纸、红章、黑字 —— 像一本摊开的川大校园手册，被红色印章盖了一下。

- 主情绪是「校园纪实」而不是「奇幻冒险」：画面主体永远是全屏实拍/写实背景，
  界面是压在上面的一层**白纸**，绝不抢画面。
- 红色只出现在**需要被按下/被强调**的地方（主按钮、选中态、名牌、关键数字），
  用一次就要有用一次的理由；页面里红点数量控制在 3~5 处。
- 黑色只承担**阅读**：正文、次要说明、极细分隔线。不用蓝灰，不用彩色中性色。
- 圆角偏大（10–32px）但克制：卡片 14–18px，胶囊 999px，弹窗 24–32px。
- 阴影用**暖黑**（`rgba(20,16,15,α)`），不用蓝调阴影；越靠前的层阴影越大越散。

## 2. Color Palette & Roles

| 角色 | 令牌 | 值 | 用在哪 |
|---|---|---|---|
| 主红 | `--red` | `#b3121a` | 主按钮底、名牌、选中描边、关键数字 |
| 亮红 | `--red-bright` | `#d81b25` | 悬停/按下渐变顶端、事件标签 |
| 深红 | `--red-deep` | `#7d0c12` | 渐变底端、按钮描边、深色文字强调 |
| 红 50/100/200 | `--red-50/100/200` | `#fff2f2 / #ffe0e0 / #ffc4c4` | 选中底、提示底、进度、浅色块 |
| 红透 | `--red-soft` | `rgba(179,18,26,.10)` | 胶囊底、幽灵按钮悬停 |
| 红晕 | `--red-glow` | `rgba(179,18,26,.32)` | 红色元素的投影/焦点环 |
| 白 | `--paper` | `#ffffff` | 面板、卡片、对话框、按钮底 |
| 暖白 | `--paper-2` | `#faf7f6` | 面板渐变底、次级面 |
| 浅灰白 | `--paper-3/4` | `#f3edec / #e9e1e0` | 分隔、输入框描边、禁用底 |
| 墨黑 | `--ink` | `#14100f` | 正文、标题 |
| 中墨 | `--ink-2` | `#4d4543` | 说明、次要信息 |
| 淡墨 | `--ink-3` | `#8f8582` | 占位、时间戳、禁用文字 |
| 发丝线 | `--hair` | `rgba(20,16,15,.12)` | 1px 分隔、卡片描边 |

语义：**涨 = 墨黑，跌 = 红**（`--up` / `--down`）。在红白黑体系里，红色天然代表「损失/危险」，
绿色被刻意排除，避免三色打架。

## 3. Typography Rules

| 层级 | 令牌 | 字号 / 字重 | 用途 |
|---|---|---|---|
| 大标题 | `--t-3xl` | 34 / 700，衬线 | 标题页游戏名 |
| 标题 | `--t-2xl` | 28 / 700 | 弹窗标题、结局名 |
| 小标题 | `--t-xl` | 22 / 600 | 面板小节 |
| 正文 | `--t-base` | 16 / 400 | 对话正文（行高 1.85） |
| 说明 | `--t-sm` | 14 / 400 | 选项数值、卡片副标题 |
| 标签 | `--t-xs` | 12 / 600（字距 .06em） | 印章、步骤、状态胶囊 |

- 中文正文 `--font`（PingFang / 微软雅黑 回退链）；**标题与编号用衬线** `--font-display`（Georgia / 宋体）。
- 红色大标题不描边、不加投影；白字红底时才用 `rgba(255,255,255,.28)` 的内高光。

## 4. Component Stylings

**主按钮 `.btn--primary`**
白字、红渐变（`--red-bright → --red → --red-deep`）、内高光、`--red-glow` 投影；
悬停上浮 2px 并加强投影；按下下沉 1px 且内阴影加深 —— 「能按」的手感优先于「好看」。

**选项 `.vn-choice`**（每回合 6 个行动）
白卡 + 1px 发丝描边 + 左侧 3px 红竖条；悬停整块变红、白字，并从左到右扫过一道高光；
按下微缩；锁定态灰化、红竖条转淡墨、不参与入场动画。

**对话框 `.vn-dialogue__box`**
白纸渐变 + 18px 圆角 + 大而散的暖黑投影；左上角红色名牌（胶囊）压住边框。

**存档卡 `.vn-slot`**
白卡、悬停上浮；空位虚线 + 暖白底；自动存档左侧 3px 红边以示区别。

**开关 `.vn-switch`**
胶囊；关闭为浅灰白，开启为红渐变 + 内高光 + 红晕投影。

**弹窗 `.vn-modal` / 事件 `.vn-event__card`**
24–32px 圆角、白纸底、`--shadow-3`；入场 260–300ms 缩放淡入。

## 5. Layout Principles

- 4px 基线：`--sp-1..10`（4/8/12/16/20/24/32/40）。
- 主舞台固定四层：**背景 → 立绘 → HUD/选项/对话框**；选项条 2 列 × 3 行，居中偏右，给左侧立绘让位。
- 安全区：底部约 25% 会被对话框盖住，左侧约 30% 立绘常驻。
- 弹窗内容宽度上限约 640px；设置/图鉴类长内容出现滚动而不是压缩。

## 6. Depth & Elevation

| 层 | 阴影 | 场景 |
|---|---|---|
| 0 | 无 | 背景、分隔线 |
| 1 | `--shadow-1` | 选项卡、HUD 胶囊 |
| 2 | `--shadow-2` | 抽屉、弹窗 |
| 3 | `--shadow-3` | 结局卡、事件卡 |
| 红 | `0 8-12px 20-26px var(--red-glow)` | 红底元素（主按钮、名牌、选中） |

## 7. Do's and Don'ts

**Do**
- 红色只标「主操作 / 当前选中 / 关键数字」；
- 面板用白或暖白，靠阴影分层，不靠边框加粗；
- 动效服务于「状态变化」（切换场景、翻开弹窗、按下按钮），时长 200–420ms；
- 所有动效在 `.reduce-motion` 或 `prefers-reduced-motion` 下关闭。

**Don't**
- 不要出现蓝色系（旧皮肤残留一律映射到红/白/黑）；
- 不要用彩色渐变做面板底（只允许白 → 暖白）；
- 不要给红色大写标题加描边/外发光；
- 不要用绿色表示「上涨」—— 涨用墨黑，跌用红；
- 不要在同一个视野里放两种红色块（会互相削弱）。

## 8. Responsive Behavior

| 断点 | 变化 |
|---|---|
| ≥ 1440px | 标题卡 720px 宽；选项条 2 列；立绘 380–510px |
| 880–1439px | 标题卡自适应；选项条仍 2 列，间距收窄 |
| 560–879px | 创建页单栏；立绘缩小；HUD 折行 |
| ≤ 560px | 选项条 88vw 置顶；对话框 96vw；隐藏立绘占位框 |

## 9. Agent Prompt Guide

要改这套界面时，按这个顺序描述需求：

1. **改颜色**：只动 `:root` 里的 `--red*` / `--paper*` / `--ink*`，不要写新的 hex；
2. **改组件质感**：改第 20 节（组件升级）里对应类，不动第 1~18 节的尺寸规则；
3. **改版式**：改 `src/ui/ui.js` 的结构函数（`titleScreen` / `dialogueBox` / `actionChoices`），
   CSS 只做视觉；
4. **加动效**：优先 CSS `@keyframes` + 类名；需要「只在状态变化时播放」时，
   在 `render()` 里比对指纹后挂类（参考 `.vn-stage.is-scene-change`）；
5. 改完必须跑 `node tests/smoke.mjs`、`tests/verify_ui.mjs`、`tests/verify_m1.mjs` 与 `tests/unit/*`。

> 红线：`src/ui/ui.js` 只读 GameState，不碰 DOM 之外的存储/随机数；`css/` 不引外部字体与图片。
