# 音频（assets/audio/）

设置面板里的「背景音乐 / 音效」两个滑块控制这里的文件；**没放文件也不会报错**，只是没声音。

## 放什么、放哪里

| 文件 | 用途 | 什么时候响 |
|---|---|---|
| `bgm/theme.mp3` | 标题页 / 创建角色 | 打开游戏时循环 |
| `bgm/campus.mp3` | 游戏内 | 进入游戏后循环 |
| `sfx/click.mp3` | 按钮、选项卡 | 点击时 |
| `sfx/choice.mp3` | 确认选项 | 选择行动时 |
| `sfx/toast.mp3` | 提示 | 弹 toast 时 |

- 格式优先 `.mp3`（兼容性最好），也支持 `.ogg` / `.m4a`，改文件名后同步改 `src/audio/audio.js` 里的 `BGM_TRACKS` / `SFX_TRACKS`；
- 建议 BGM 单曲 **1–3 MB / 128 kbps** 以内，循环点做平（首尾电平一致），否则循环时会“咔”一下；
- 音效 **< 200 KB**，长度 0.2–0.6 秒最自然。

## 音量与静音

- 两个滑块都是 0–100，拖动即时生效，保存后写入设置（`scusim:settings`）随下次启动恢复；
- 内部把 0–100 换算成 `<audio>.volume` 的 0–1；
- 浏览器禁止自动播放时，BGM 会静默失败，等玩家第一次点击后即可正常播放。

## 代码位置

`src/audio/audio.js` —— 纯逻辑、顶层不碰 DOM，Node 里可以直接 import 测试；浏览器里用 `<audio>` 播放。
